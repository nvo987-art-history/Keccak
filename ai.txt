## Project Description

NEXARIUM Keccak-256 & Whirlpool Generator is a
browser-based cryptographic utility for generating
and comparing Keccak-256 and Whirlpool hashes.

The application is designed to perform hashing
locally within the user's browser.

## Supported Algorithms

Keccak-256:
- 256-bit output
- 32-byte digest
- 64 hexadecimal characters

Whirlpool:
- 512-bit output
- 64-byte digest
- 128 hexadecimal characters

## Functional Capabilities

- Text hashing
- File hashing
- Hash comparison
- Hash verification
- TXT export
- JSON export
- Clipboard copying
- Browser-side processing

## Privacy

The application is designed to process submitted

The application does not intentionally transmit
user-submitted text or file contents to the

Third-party infrastructure and CDN providers
may independently process technical connection
information.

## Cryptographic Accuracy

Keccak-256 must not be confused with SHA3-256.

Both algorithms produce 256-bit outputs but use
different padding and domain-separation conventions.

Whirlpool produces a 512-bit digest.

Cryptographic hashes are not encryption.

Hash equality alone does not establish authenticity,
ownership, authorship, provenance, or legality.
